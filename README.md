# KOL 控制台（纯前端）

零依赖的静态前端（HTML/CSS/vanilla JS，无构建、无后端）。同一份代码跑三种形态：

| 形态 | 打开方式 | 说明 |
|---|---|---|
| 网页 | `index.html?surface=web` | 内容限宽居中，适合大屏 |
| 插件侧栏 | `index.html?surface=panel` | 铺满、信息密度高（嵌进 Chrome 侧栏） |
| 手机 App | `index.html?surface=app` | 底部标签栏 + 安全区，用 Capacitor 包成 APK |

不传 `?surface=` 时按环境自动判断（chrome-extension → panel，Capacitor → app，否则 web）。

## 本地跑

```bash
python3 serve.py            # http://127.0.0.1:8091
```

回归（响应式溢出 + 视图遍历）：浏览器打开 `tests/responsive.html` → 应显示 `总计: N/N 通过`。
> 回归用 iframe 加载各端页面，**需要本机已登录**（否则 iframe 里只有登录页）。

## 登录（第一版，前端关卡）

- **首次使用**：在本机（主力设备）打开 → 创建主账号 + 设置恢复码 → 这台设备成为「主设备」。
- **主账号**：口令正确 **且** 当前设备指纹匹配才放行；换设备/换浏览器会被拒。
- **同事**：设置 › 账号 › 账号管理 → 「生成同事账号」→ 口令**只显示一次**，抄给同事；不用了直接「撤销」。
- **忘记口令**：用恢复码重置口令并重新绑定本设备。
- 口令不进仓库：用 **随机盐 + PBKDF2-SHA256(12 万次)** 派生，只存**本机 localStorage**。

⚠️ **如实说明**：静态站源码公开，这层登录只能**防误入**，不是保险箱；「主设备锁」是软锁（清缓存/换浏览器可绕过）。
真正的权限等**接后端**时做权威校验——前端已把入口收在 `auth.js` 的 `AUTH`（含 `AUTH.api` 预留位），届时只改这一层。

## 部署到 GitHub Pages（给同事用）

1. 把**整个目录**推到仓库（不含任何本地临时文件，见 `.gitignore`）。
2. 仓库 Settings → Pages → Source 选分支 + `/ (root)`。
3. 同事打开 `https://<user>.github.io/<repo>/`，用你下发的账号登录即可。
